M10 GPS EKF tuning for high-vibration environments

AVIONICS NAVIGATION EKF3

We are experiencing intermittent position fly-aways on the VTOL test platform when transitioning from hover to forward flight. Log analysis shows high innovations in velocity (VelN/VelE) right as the rear motor spins up.

The platform uses the standard M10 GPS module (P/N: NAV-M10-02) hard-mounted to the carbon fiber avionics deck. We've confirmed no magnetic interference issues with the compass.

EKF3 IMU0 is using GPS
EKF3 IMU1 is using GPS

MSG: GPS Glitch or Compass error

I suspect vibration is causing the EKF to reject the GPS velocity data. Should we adjust `EK3_VELNE_M_NSE` or focus entirely on mechanical isolation first?

Mechanical isolation is absolutely critical here. Do not try to tune out a fundamentally bad mechanical setup via EKF parameters; you will only mask the problem and degrade overall navigation performance.

The M10 module is highly sensitive to high-frequency vibrations typically seen on rigid carbon frames. Follow this sequence:

  1. Implement SOP-NAV-014 (Vibration Isolation Mounting for IMU/GPS) using Kyosho Zeal gel pads.
  2. Run a brief hover test and check the `VIBE` log messages. `VibeX` and `VibeY` must be consistently below 30m/s/s, ideally below 15m/s/s.
  3. Only if vibrations are acceptable but position glitches persist during specific transitions, consider increasing `EK3_VELNE_M_NSE` slightly (from default 0.5 to 0.7) to make the filter less trusting of instantaneous velocity spikes.

Also, verify your wiring harness isn't transmitting vibrations mechanically to the module casing.
