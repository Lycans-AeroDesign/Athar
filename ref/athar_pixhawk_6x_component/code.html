Pixhawk 6X v6X.2

Manufacturer: Holybro | Part No: HB-PX6X-001

Component Summary

The Pixhawk 6X is a highly capable flight controller utilizing the STM32H753 processor. Engineered for demanding industrial and commercial applications, it features triple-redundant IMUs mounted on isolated, vibration-damped domains. This specific iteration guarantees robust performance in high-EMI environments typical of heavy-lift multicopters and fixed-wing VTOL transition aircraft.

Core Parameters
Processor STM32H753 32-bit Arm Cortex-M7, 480MHz
Input Voltage 4.75 ~ 5.5V DC
Weight 36.5g (without baseboard)
Dimensions 38.8 x 38.8 x 17.5 mm
